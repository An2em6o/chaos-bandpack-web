### 追补：用户 pnpm dev 下"按钮没 CSS / 左右排列"根因

根因不是样式没写，而是 **Astro 把 .astro 模板里的 `<style>` 当 scoped 样式编译**（加 `data-astro-cid-*` 后缀）：JS `createElement` 动态创建的 `.slot`/`.slot-actions`/按钮没有 cid 属性，scoped 选择器全部匹配不上 → 表现为"和没 CSS 一样"、按钮退化为浏览器默认 inline 左右排列。dist 里早就带 cid，此前未察觉。

修复：
1. `<style>` → `<style is:global>`（全局样式，动态 DOM 可命中）
2. esbuild 重打 `public/icons.js`（30.7kb，与当前源码同步）
3. 引用 bump `/icons.js?v=4` 破缓存
4. astro build 重建 dist，5 项正则验证全过（无 cid、全局 slot-action、pack-card、v=4）

**长期规则：本项目 .astro 页面里的 `<style>` 必须写 `is:global`；改 scripts_*.ts 后必须 esbuild 重打 public/*.js 并 bump ?v=N。**
